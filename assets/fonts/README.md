# Bundled fonts (D-130)

Both families are licensed under the SIL Open Font License 1.1 (each `OFL.txt` sits next to its font files). They are bundled as assets and never fetched at runtime.

| Family | Use | Version / source revision | Licence | Source |
|---|---|---|---|---|
| Instrument Sans | text (UI labels, body) | variable font `wdth,wght` as published in google/fonts at commit 0b58fb370093f9a9f4ff785d94405710b79de67c (upstream: Instrument/instrument-sans) | SIL OFL 1.1, copyright 2022 The Instrument Sans Project Authors | https://github.com/google/fonts/tree/main/ofl/instrumentsans , https://github.com/Instrument/instrument-sans |
| Barlow Semi Condensed | numbers and readouts (Regular, Medium, SemiBold, Bold) | static TTFs as published in google/fonts `ofl/barlowsemicondensed` (upstream: jpt/barlow) | SIL OFL 1.1, copyright 2017 The Barlow Project Authors | https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed , https://github.com/jpt/barlow |

Why these two: Instrument Sans is a neutral modern grotesk with full Latin Extended coverage (Turkish letters); Barlow Semi Condensed is a highway-signage derived, semi-condensed face with tabular figures, which suits instrument readouts.

Files are used unmodified. Update by replacing the files and the revision above.
